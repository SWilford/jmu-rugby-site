# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through a public issue,
discussion, pull request, or social-media post.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected page or component, reproduction steps, potential impact,
and any suggested mitigation. Do not include credentials, authentication
tokens, private member information, or other sensitive data beyond what is
strictly necessary to explain the issue.

The club aims to acknowledge a report within three business days, provide an
initial assessment within seven business days, and give a progress update at
least every fourteen days until the report is resolved or closed. These are
response targets rather than guarantees.

Please allow a reasonable remediation period before making a report public.
Good-faith research that avoids privacy violations, service disruption, data
destruction, social engineering, and access beyond what is needed to
demonstrate the issue is welcome.

## Supported version

Security fixes are applied to the version currently deployed at
<https://www.jmumensrugbyclub.com/> and the repository's default branch.
